# Resume Builder — Frontend

React frontend for the Resume Builder module, built with Vite, React, and Tailwind CSS v4.

## Tech Stack
- React
- Vite
- Tailwind CSS v4
- React Router (coming soon)
- Axios (coming soon)

## Getting Started

```bash
npm install
npm run dev
```

Runs the app locally at `http://localhost:5173`
